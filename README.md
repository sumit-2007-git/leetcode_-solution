## 📌 About This Repo

> *"Every expert was once a beginner who refused to give up."*

Consistency beats intensity. This repository is proof of that — a growing collection of problems solved one day at a time, one line of code at a time. No shortcuts, no giving up when a problem looks impossible on the first read.

If you're reading this while grinding through your own DSA prep — **keep going**. The problem that feels unsolvable today will feel easy in a month. Every solution in this repo was once a blank screen and a "how do I even start" moment too.

This repo isn't just a code dump — it's a study resource. Each solution includes:

- ✅ Clean, working code
- 📖 Problem explanation in plain language
- ⏱️ Time & space complexity breakdown
- 💡 The *why* behind the approach, not just the *what*
- 🔍 Dry runs so you can trace the logic yourself

**Whether you're prepping for interviews, building consistency, or just starting out — feel free to fork this, learn from it, and start your own streak today.**
